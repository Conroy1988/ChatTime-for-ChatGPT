# Chrome Web Store listing

## Name

ChatTime for ChatGPT — Message Timestamps

## Summary

See the original date and time of every ChatGPT message. Simple, customisable, private, and built for Chromium browsers.

## Category

Tools

## Language

English (United Kingdom)

## Detailed description

ChatTime adds the missing time context to ChatGPT.

Every prompt and reply can display its original creation date and time directly inside the conversation. The design is quiet by default, works with light and dark themes, and can be changed from the extension panel.

Features:

• Original message times — not the time the page happened to load
• Timestamps for every message, your messages only, or ChatGPT replies only
• 12-hour and 24-hour clock formats
• Local time and UTC
• Optional date and seconds
• Above-message and below-message placement
• Quiet text and soft-chip styles
• Automatic support for streamed replies and ChatGPT page navigation
• Right-to-left conversation safety
• Optional Ko-fi support link in the settings panel

Private by design:

ChatTime has no analytics, advertisements, trackers, accounts, remote code, or developer server. It makes no automatic external network requests and never collects or transmits conversation content. Its only extension permission is storage, used for display preferences. The optional Ko-fi link opens only when deliberately selected.

Works on chatgpt.com in Brave, Google Chrome, Microsoft Edge, and other current Chromium browsers.

ChatTime is an independent, unofficial extension and is not affiliated with or endorsed by OpenAI.

## Permission justification

### storage

Stores and optionally browser-syncs display preferences: enabled state, 12/24-hour clock, local/UTC, date, seconds, message role, placement, and appearance. No conversation content is stored.

### Site access: chatgpt.com

Required for the single purpose of reading message creation times already loaded in the page and displaying them beside the corresponding messages. The extension does not transmit, retain, or analyse message content.
