# Changelog

All notable changes to ChatTime are documented here.

## 1.0.0 — 2026-08-09

- Initial public release.
- Original per-message timestamps for ChatGPT conversations.
- Local/UTC and 12/24-hour display controls.
- Optional dates and seconds.
- User/reply visibility and above/below placement controls.
- Quiet text and soft chip appearances.
- Live streamed-message and navigation support.
- Privacy-first Manifest V3 package with only the `storage` permission.
