# Privacy Policy

**Effective date:** 9 August 2026

ChatTime for ChatGPT does not collect, store, transmit, sell, or share personal data.

## Data access

The extension runs only on `https://chatgpt.com/*` so it can add timestamps to messages displayed on that website. Message text is not copied, logged, retained, or transmitted. Original message creation times already present in ChatGPT's loaded page state are read locally and displayed in the page.

## Browser storage

The extension uses Chromium's `storage` permission only for display preferences such as clock format, time zone, placement, and visibility. These settings contain no conversation content. Depending on the user's browser configuration, Chromium may sync those preferences between signed-in browsers.

## Network communication

The extension makes no external network requests and has no analytics, advertising, telemetry, remote code, or developer-operated server.

## Changes

Any material change to this policy will be documented in the repository and included with a versioned extension update.

## Contact

Privacy questions can be raised through the public GitHub issue tracker for this project.

ChatTime is an independent, unofficial extension and is not affiliated with or endorsed by OpenAI.
